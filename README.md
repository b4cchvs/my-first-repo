# 🔮 鑑定タスク管理アプリ

鑑定業務向けの個人用タスク管理 Web アプリです。顧客ごとに「無料鑑定／本鑑定／アップセル」を管理し、毎日のタスクをチェックしながら鑑定結果を記録できます。

## 特徴

- **個人利用・PC ブラウザ向け**（ログイン不要）
- **バックエンド・ビルド不要** — `index.html` を開くだけで動作
- **データはブラウザに自動保存**（localStorage）。アプリを閉じても消えません
- **ダークモード切替**対応

## 使い方

`index.html` をダブルクリックしてブラウザで開くだけです。

> ※ ローカルサーバーで開きたい場合は、このフォルダで `python3 -m http.server` を実行し、
> ブラウザで `http://localhost:8000` を開いてください。

## 機能一覧

### タスク一覧（毎日のタスク／今日のタスク）
- **2カラム表示**
  - `毎日のタスク` … スケジュールが「毎日」のタスク
  - `今日のタスク` … 期限が**今日**のタスク
  - （上記以外の未来の期限タスクは一覧には出ず、カレンダーで確認します）
- **作成**：種別を選択して追加
  - `タスク名入力` … 自由なタスク名。スケジュールは `毎日` か `期限あり` を選択
  - `無料鑑定` … **顧客名・鑑定内容**を入力して追加（**期限なし**。当日の「今日のタスク」に入ります）
  - `本鑑定` … **顧客名・鑑定プラン（松／竹／梅）・期限・鑑定内容**を入力して追加
    （プラン料金が顧客の**LTVに自動加算**されます：松 ¥14,800／竹 ¥7,980／梅 ¥0）
  - `アップセル` … **顧客名・期限・鑑定内容**を入力して追加
    （入力した顧客は「顧客管理」に**自動で登録**されます）
- **毎日のタスクの自動リセット**：「毎日」のタスクは**日付が変わる（24時）と全てのチェックが外れます**
- **完了チェック**：完了したタスクは**全体が暗く**なり、スケジュール欄が「✅ 完了」に変わります
- **詳細ポップアップ**：鑑定タスクをクリックすると鑑定内容のポップアップが開きます（アップセルは結果欄なし）
- **編集・削除**：各タスク行のボタンから操作
- **カレンダー**：一覧の下に月カレンダーを表示。期限タスクのある日に印が付きます
  （**赤＝期限切れ／緑✓＝その日のタスクが全て完了**）。日付クリックで内容を確認できます
- **キャラクター（ドラクエ風）**：タスク一覧の右側にキャラアイコン・なまえ・ステータス
  （**HP / MP / パワー / チャーム / ゴールド**）を表示。ステータスはアプリの活動量から自動算出されます
  - ゴールド＝全顧客のLTV合計、パワー＝完了タスク・本鑑定数、チャーム＝顧客数・アップセル数、Lv＝完了タスク数
  - 「なまえ・アイコン」ボタンから名前とアイコンを変更できます

### 顧客管理
- **顧客の登録・編集・削除**
- **一覧表示（テーブル）**：顧客名・**フェーズ**・**LTV（累計売上）**を列で表示
- **フェーズは自動**：鑑定タスクの種別に応じて自動で進みます
  （本鑑定タスクを作成 → 本鑑定／アップセルタスクを作成 → アップセル。手動設定は不要）
- **ソート**：一覧の「フェーズ」「LTV」見出しをクリックすると並び替え（再クリックで昇順／降順を切替）
- **フェーズで表示／非表示**：一覧上部のフェーズチップで、表示するフェーズを絞り込み可能
- **鑑定結果の格納**：各顧客の「鑑定結果」ボタン → 種別ボタンを選ぶと結果ポップアップが開きます
  - **無料鑑定**：開いた時点で内容を**自動でクリップボードにコピー**（「📋 コピー」ボタンで再コピーも可）
  - **本鑑定**：結果の入力・保存
  - **アップセル**：結果欄なしの空ポップアップ
- **メモ**：自由メモ欄

## 画面構成

| 画面 | 内容 |
| --- | --- |
| タスク一覧 | 毎日のタスク（完了チェック）一覧 |
| 顧客管理 | 顧客一覧と鑑定タイプ設定 |
| 各ポップアップ | タスク作成／編集、タスク詳細（鑑定結果）、顧客編集 |

## 技術スタック

- HTML / CSS / Vanilla JavaScript（フレームワーク・依存ライブラリなし）
- データ永続化：ブラウザの localStorage

## ファイル構成

```
index.html   画面のマークアップ
styles.css   スタイル（ライト／ダークテーマ）
app.js       アプリのロジック（状態管理・描画・永続化）
```

## 注意事項

- データは**この PC のこのブラウザ**にのみ保存されます。別の PC・ブラウザとは共有されません。
- ブラウザのデータ（サイトデータ）を削除すると、登録内容も消えます。
